# 프로젝트 초기 설정

## 초기에 설정해야 되는 기능들
- 플랫폼 : 크로스 플랫폼 (PC, Android)
- 그래픽 : URP를 사용한 그래픽 처리
- 맵 : Probuilder를 사용해 맵 생성. 발탄 1관문 보스 맵을 검색해서 사진을 보고 ProBuilder로 만들기
- 카메라 : 쿼터뷰를 규현한 Cinemachine으로 구현
- Asset Management : Addressables
- Input : Input System을 사용.
- AI : NavMeshAgent를 이용한 AI, PhilJoon Package의 StateTree Tool을 이용하여 AI의 일련 과정을 설정
- Package : PhilJoon Package 추가 (GAS, StateTree, Addressables 시스템을 래핑한 구조, UniTask를 이용한 비동기 방식)
- Unity Test Framework : 딜량 수치와 시나리오를 Test와 UnityTest 메서드를 이용해서 확인
- 멀티플레이 : NetCode for GameObject를 이용해서 Delay 로비와 최대 4인 플레이가 가능할 수 있도록 제작. NetCode 적용 전에는 Custom AI들로 파티 플레이 가능하게 만듦.
- 저장 : 후에는 Playfab을 사용할 예정. 그 전에는 로컬 json 파일에 저장할 수 있도록 만듦.
- UI : uGUI를 사용하여 제작.

## 아직 설정하지 않는 사항들
- Assets : 아직 구체적인 Asset(Mesh, Animation, Material 등등)은 정해지지 않았기 때문에 일단은 Probuilder나 기본 Mesh들을 직접 조합해서 구현한다. 캐릭터는 캡슐 Mesh로 만들고 보스몬스터도 기본 Mesh들을 조합하여 구현한다.
