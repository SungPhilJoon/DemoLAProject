# 3차 변경 사항 (2026-11-07 ~ 08)

> 원작과 "똑같이" 요청 중 **원작의 스킬 · 각인 수치 · 맵 · UI 화면을 그대로 옮기는 것은 하지 않았다** (2차 문서의 방침과 같음).
> 대신 같은 장르의 **시스템** (넉백 면역 · 무력화 등급 · 스킬 장착 · 대기실 준비 확인 · 아이덴티티 Z/X · 도감식 장착 등)을 구현하고 내용/수치는 이 프로젝트 고유로 채웠다.

## 1. 전투 · 보스

| 항목 | 내용 | 주요 코드 |
|---|---|---|
| 보스 밀림 방지 | 보스 · 몬스터 에이전트는 회피 끔 + 우선순위 0 → 플레이어가 밀 수 없음. 겹치면 플레이어만 밀려남 | `RaidSpawner.addAgent`, `ActorMotor.separateFromEnemies` |
