# 개발 기능

## 직업

- 서머너
- 인파이터
- 슬레이어
- 도화가

## 컨텐츠

컨텐츠는 UI에서 설정할 수 있도록 하고 로스트아크의 UI랑 똑같이 구현한다.
모든 각인과 보석, 카드는 구비가 되어있어, 맘대로 설정할 수 있도록 한다.

## 능력치

로스트아크의 능력치 시스템을 따라한다. 능력치 시스템은 검색하여 로아인벤이나 로아사이트, 로아온에서 정보를 얻어 유사한 계산식으로 처리할 수 있게한다.

### 장비

로스트아크 시즌2 기준으로 환각 세트를 구현해놓는다. 장비 스탯을 전부 구현할 수 있도록 GameplayEffect를 구현해놓는다.

### 악세사리

각인 스탯은 3, 5로 붙은 악세사리들을 가지고 있는 상태로 시작한다. 로스트아크 시즌2를 기준으로 만든다.

### 각인

기준은 시즌2 기준으로 모든 각인을 구현하고 로스트아크에서 설정을 변경하는 것이랑 똑같이 설정 할 수 있도록 만든다. 모든 각인은 3레벨 전설까지 되있다.

### 카드

기준은 시즌2 기준으로 세구빛, 암구빛, 남바절 카드 세트를 구현하고 로스트아크에서 설정을 변경하는 것이랑 똑같이 설정 할 수 있도록 만든다. 카드는 모두 최대 각성이 되있는 상태이다.

### 보석

위 4가지 직업의 모든 멸화, 홍염 보석을 10레벨까지 만든 보석을 가지고 있다. 보석 장착은 로스트아크 시즌2를 기준으로 설정할 수 있게 한다.

### 강화

모든 강화 재료는 무한이다. 강화는 로스트아크에 있는 기능 그대로 사용할 수 있도록 만든다.

### 스킬

모든 스킬포인트를 얻은 상태이다. 시즌2를 기준으로 최대 스킬포인트까지 얻은 상태이며 트라이포드 기능도 구현하도록 한다. 트라이포드가 올라갈수록 스킬이 변경될 수 있도록 GAS 시스템을 만들어야한다.
스킬은 Ability, 효과는 GameplayEffect, 캐릭터와 몬스터의 능력치는 AttributeSet, 스킬 이펙트는 GameplayCue를 사용해서 구현하도록 하고 트라이포드는 Ability에 새로운 GameplayEffect를 동적으로 추가해서 스킬을 강화시킬 수 있도록 만든다.

## 보스 몬스터 패턴

pattern_analysis_valtan.xlsx 파일을 참고하여 몬스터 패턴을 만든다. 몬스터 패턴은 StateTree와 GAS를 사용해서 모듈식 개발로 언제든 Editor에서 설정하고 변경할 수 있도록 만든다.

## 맵

Probuilder로 일단 구현한다. Probuilder로 만든 맵은 발탄 레이드 맵의 사진을 검색해서 확인하여 직접 Texture를 만들어서 붙이는 방식으로 구현한다.

## 기믹

pattern_analysis_valtan.xlsx과 로스트아크 사이트, 로아인벤의 내용을 바탕으로 발탄 레이드의 기믹을 구현한다.
