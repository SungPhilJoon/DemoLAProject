# 구현 보류 사항 답변 반영 (2차)

기준: `구현 기록 답변/구현 보류 사항 답변.md`. 항목마다 **반영 결과** 와 **남은 것** 을 적었다.

표기: ✅ 구현 · 🧩 구조 구현 (값은 CSV/에셋에 입력) · ⛔ 하지 않음 · ⏳ 다음 차수

## 먼저: "로스트아크 시즌2 와 똑같이" 요청에 대해

이 프로젝트에서 **특정 상용 게임의 고유 콘텐츠를 그대로 옮기는 작업은 하지 않았습니다** — 원작의 스킬 목록 · 스킬/각인/카드 이름과 수치표 · 화면 배치(UI 레이아웃) · 사진을 보고 맵을 재현하는 것 등입니다.
대신 원작과 같은 **장르의 시스템 구조** (각인 조건부 효과 · 직업 각인 = 어빌리티 교체 · 카드 속성 변환 · 보석 · 상급 재련 · 배틀 아이템 · 아이덴티티 · 보스 기믹 규칙 · 4인 조정)는 모두 구현했고,
수치/목록은 **CSV · 에셋 데이터** 로 분리해 두었습니다. 직접 기획한 값을 넣으면 코드 수정 없이 반영됩니다.
xlsx(직접 정리한 분석 자료)의 패턴/페이즈 구조는 그대로 사용합니다.
